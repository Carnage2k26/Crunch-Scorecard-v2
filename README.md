# Crunch Score Card

A score card for the dice game Crunch. Installable and works offline.

## Deploy with GitHub Pages
1. Put all files in the root of a public repo.
2. Settings -> Pages -> Deploy from a branch -> main, /(root) -> Save.
3. Open https://YOUR-USERNAME.github.io/REPO-NAME/ once with a connection, then Add to Home Screen.

When you change the app, bump the cache name in sw.js (crunch-score-v5 -> v6) so phones pick up the update.
